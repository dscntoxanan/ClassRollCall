班级随机点名 v1.0
=================

一、这是什么
  给班里用的随机点名小程序。单文件、免安装、32 位，Win7 及以上都能跑。
  名单写死在程序里，概率可以在后台随时调。

二、怎么用
  1) 双击 ClassRollCall.exe
  2) 用按钮两边的「−」「+」选这次抽几个人（1 ~ 53，鼠标滚轮也能调）
  3) 按空格或点「抽 N 位」开始
     同一次里不会重复；换一次再抽，可以再抽到同一个人（按后台权重）
  4) ↑ ↓ ← → 也能改人数，F5 重新同步，Esc 退出

  启动时会 ping 一下服务器（100 毫秒超时）：
  能连上 -> 立刻同步后台设置的概率
  连不上 -> 直接用本机缓存的概率，界面不会有任何提示，照常点名
  失败后程序会在 8 秒、25 秒、1 分钟时自动再试；
  想立刻重试就按 F5。

三、后台（调概率）
  地址：https://你的域名/api/admin
  用管理员 Token 登录（Token 找管理员要，不写在任何文件里）
  权重：0 表示本轮永不抽到，数值越大越容易被抽中；
  页面右侧显示的是实际占比（权重 / 所有人权重之和）。
  改完点「保存修改」，客户端下一次启动（或按 F5）生效。

四、关于杀毒软件
  这个 exe 是纯 Win32 程序，没加壳、没混淆、不联网常驻，只在你按 F5
  或启动时访问一次 你的域名，正常情况下不会报毒。
  如果某台机器仍然拦截，二选一：
    a) 把本目录加入杀软的「信任区 / 白名单」（学校机房最常见做法）
    b) 把文件哈希提交给杀毒厂商做误报申诉
  注意：exe 用自签测试证书签名，Windows 7 默认不认识这个证书，
  想显示「WhiteShadow Studio」发布者，就双击 install-cert.bat，
  在 UAC 窗口点「是」即可（一次性，只影响「未知发布者」提示，不影响程序功能）。

五、卸载
  删除 exe 即可。
  如果装过证书，双击 uninstall-cert.bat 可以移除证书信任（需要管理员）。
  本地缓存位置：
  %APPDATA%\XananRollCall\state.dat
  需要「忘记抽过谁」时，直接删掉这个文件。

六、常见问题
  Q: 右上角一直显示「离线 · 同步失败」？
  A: 学校网络把 ICMP 或 你的域名 挡了。不影响点名，只是概率用本地的。
  Q: 后台改了概率，客户端没变？
  A: 客户端只在启动时同步；按 F5 可以立刻同步一次。
  Q: 换电脑/重装后名单进度乱了？
  A: 进度存在 %APPDATA%，换机器就是新的开始，属正常。
